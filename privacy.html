Privacy Policy

Glance Calendar is a personal-use application used to display upcoming events from a user's Google Calendar inside a local Glance dashboard.

Google Calendar data

The application accesses Google Calendar data only for the purpose of retrieving and displaying calendar events in the user's personal dashboard.

The application does not sell Google user data and does not share Google user data with third parties.

The application does not use Google Calendar data for advertising, profiling, or any purpose unrelated to the dashboard functionality.

Storage

Calendar data is used for the dashboard display. The local Glance setup stores only the credentials required to access the user's Google Calendar as configured by the user. No separate cloud database is operated by this application.

Contact

This application is maintained for personal use.
